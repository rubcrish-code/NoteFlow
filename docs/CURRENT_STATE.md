# Текущее состояние NoteFlow

Дата фиксации: 15.06.2026
Ветка: wip/editor-ui-polish

## Реализовано

- Tauri + React + TypeScript desktop-приложение.
- Поддержка Windows и подготовка к macOS.
- Основной интерфейс NoteFlow по актуальному HTML-макету.
- TipTap/ProseMirror редактор.
- Автоматическое распознавание Markdown при вставке.
- Основные команды форматирования.
- Выноски.
- Сворачиваемые блоки.
- Упоминания заметок.
- Даты.
- Формулы в базовом виде.
- Меню вставки блоков.
- Меню заметки.
- Создание проектов в памяти.
- Расширенная палитра тегов.
- Регулируемые панели ИИ-чата по базе.
- Режим фокуса.
- Светлая и тёмная темы.

## Проверки

- npm run typecheck — успешно.
- npm run build — успешно.
- npm run tauri dev — успешно.
- npm run test — 20 из 21 теста успешно.

## Последние замечания пользователя

1. Верхняя панель должна отвечать за форматирование текста и текущего блока.
2. Нижнее меню + должно использоваться только для вставки сложных блоков.
3. Убрать дубли заголовков, списков, цитаты и кода из нижнего меню.
4. Добавить выбор семейства шрифта.
5. Добавить выбор размера текста.
6. Добавить сброс шрифта и размера.
7. Кнопка AI должна быть кликабельной даже без модели.
8. Без модели AI-кнопка должна вести в Настройки → Модели ИИ.
9. Самый левый сайдбар в ИИ-чате по базе должен регулироваться по ширине.
10. Нужно сохранить регулирование внутренних панелей ИИ-чата.
11. После подключения ИИ подготовить подробную пользовательскую инструкцию.
