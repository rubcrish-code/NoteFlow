# Подключение моделей ИИ в NoteFlow

NoteFlow поддерживает локальные и внешние LLM-провайдеры через настройки `Настройки -> Модели ИИ`.

## Ollama

1. Запустите Ollama на компьютере.
2. Выберите тип `Ollama`.
3. Укажите `Base URL`: обычно `http://localhost:11434`.
4. Оставьте `API key` пустым, если ваш локальный сервер не требует ключ.
5. Нажмите `Получить модели`.
6. Выберите или введите chat model, например `qwen3:8b`.
7. Нажмите `Проверить подключение`, затем `Сохранить подключение`.

Если Ollama не запущен, NoteFlow покажет ошибку о недоступном локальном endpoint.

## LM Studio

1. В LM Studio загрузите модель и запустите Local Server.
2. Выберите тип `LM Studio`.
3. Укажите `Base URL`: обычно `http://localhost:1234/v1`.
4. `API key` обычно можно оставить пустым.
5. Получите список моделей или введите ID модели вручную.
6. Проверьте и сохраните подключение.

## OpenAI-compatible API

1. Выберите `OpenAI-совместимый`.
2. Укажите `Base URL`, например `https://api.openai.com/v1` или адрес совместимого сервера.
3. Введите `API key`, если провайдер требует авторизацию.
4. Укажите chat model и при необходимости embedding model.
5. Проверьте подключение.
6. Сохраните подключение.

## Свой API

`Свой API` подходит для OpenAI-compatible серверов с нестандартными путями:

- `Путь списка моделей`, например `/models`;
- `Путь чата`, например `/chat/completions`;
- `Путь embeddings`, например `/embeddings`;
- дополнительные несекретные HTTP-заголовки в JSON.

Секретные заголовки вроде `Authorization`, `X-API-Key`, `token` и `secret` на этом этапе запрещены. Используйте поле `API key`.

## Где хранится API key

API key не хранится в SQLite, localStorage, резервных копиях или логах.

- Windows: Windows Credential Manager.
- macOS: Keychain.

В SQLite сохраняется только ссылка на секрет и обычные настройки подключения: название, тип, Base URL, модели, endpoint-пути и параметры.

После сохранения реальный ключ не показывается обратно в поле ввода. Интерфейс показывает только состояние: `Ключ сохранён` или `Ключ не задан`.

## Что отправляется провайдеру

На этапе 04A NoteFlow выполняет только проверку подключения и получение списка моделей.

- Для локальных endpoint `localhost`, `127.0.0.1` или `[::1]` данные остаются на устройстве, если сервер действительно локальный.
- Для внешних endpoint запросы уходят выбранному провайдеру.

Полноценный ИИ-чат по заметке и RAG будут подключаться на следующих этапах.

## Типовые ошибки

- `Base URL должен начинаться с http:// или https://`: исправьте адрес API.
- `Локальный endpoint недоступен`: запустите Ollama или LM Studio и проверьте порт.
- `401 Unauthorized`: проверьте API key.
- `403 Forbidden`: у ключа нет доступа к выбранной модели или endpoint.
- `404 Not Found`: проверьте Base URL и пути API.
- `Timeout`: сервер не ответил за заданное время.
- `Ответ провайдера не содержит список моделей`: endpoint списка моделей вернул неожиданный формат.
