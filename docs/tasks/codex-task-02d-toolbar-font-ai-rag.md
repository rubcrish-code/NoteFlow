## 1. Развести toolbar и меню вставки блоков

Сейчас часть функций дублируется в верхней панели и нижнем меню `+`.

Нужная логика:

- верхняя панель — форматирование выделенного текста и текущего блока;
- нижнее меню `+` — вставка нового сложного блока в позицию курсора.

Оставить в верхней панели:

- paragraph, H1–H3;
- bold, italic, underline, strike;
- inline code;
- highlight и цвет текста;
- superscript/subscript;
- списки и task-list;
- quote;
- code block;
- align;
- link;
- clear formatting;
- undo/redo;
- AI.

В нижнем меню оставить только вставку сложных блоков:

- таблица;
- выноска;
- сворачиваемый блок;
- изображение;
- файл;
- упоминание;
- дата;
- формула;
- разделитель.

Убрать из нижнего меню дубли H1–H3, обычный абзац, списки, quote и code block.

Подсказку снизу переписать так, чтобы было понятно: меню `+` предназначено именно для вставки сложных блоков.

## 2. Шрифт и размер текста

Добавить в toolbar два компактных элемента:

1. выбор семейства шрифта;
2. выбор размера текста.

Семейства без загрузки внешних шрифтов:

- Системный;
- Arial;
- Georgia;
- Times New Roman;
- Verdana;
- Courier New.

Размеры:

- 12;
- 14;
- 16;
- 18;
- 20;
- 24;
- 28;
- 32;
- 36.

Требования:

- применять к выделению или текущей позиции;
- показывать текущее значение;
- кнопка сброса к значению по умолчанию;
- работать через TipTap `TextStyle`/marks;
- не использовать `document.execCommand`;
- не ломать одну строку toolbar;
- при нехватке места объединить оба выбора в компактный popover `Шрифт`;
- поддержать светлую и тёмную темы;
- JSON и HTML должны сохранять font-family/font-size;
- при Markdown-экспорте явно задокументировать, что нестандартные шрифты и размеры сохраняются через inline HTML либо могут быть потеряны в чистом Markdown.

## 3. AI-кнопка

Кнопка AI не должна быть визуально и функционально «мёртвой».

Если модель не подключена:

- кнопка остаётся кликабельной;
- открывает popover;
- показывает текст `ИИ-модель не подключена`;
- есть кнопка `Подключить модель`;
- кнопка переводит в `Настройки → Модели ИИ`.

Если модель подключена в будущем:

- меню показывает действия для выделения/заметки.

На этом этапе не отправлять реальные запросы и не имитировать ответы.

## 4. Resize основного сайдбара в «ИИ-чат по базе»

Исправить, чтобы самый левый основной сайдбар на странице `ИИ-чат по базе`:

- регулировался по ширине так же, как на странице заметок;
- использовал общий layout-state, а не отдельную фиксированную ширину;
- имел видимый resize-handle;
- сохранял ширину в localStorage;
- сохранял collapse/expand;
- не ломал внутренние регулируемые колонки истории и источников.

Проверить:

- раскрытый основной сайдбар;
- компактный основной сайдбар;
- размеры окна 1100×700, 1440×900, 1920×1080;
- отсутствие пустых областей и обрезания.
