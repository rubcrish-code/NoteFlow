## Цель
Добавить `Ctrl + колесо мыши` для плавного масштаба и сделать, чтобы приложение при запуске с ярлыка открывалось развёрнутым.

## 1. Окно при запуске
- Открывать главное окно в `maximized`, а не kiosk/fullscreen.
- Не скрывать панель задач Windows и системные элементы macOS.
- Пользователь после запуска может вручную изменить размер.
- Минимальный размер оставить около `1100×700`.
- Стартовый размер до максимизации около `1440×900`.
- Проверить `src-tauri/tauri.conf.json` и при необходимости Rust/JS инициализацию окна.

## 2. Ctrl + Wheel zoom
- `Ctrl + Wheel Up` — увеличить.
- `Ctrl + Wheel Down` — уменьшить.
- Шаг 5%.
- Диапазон 80–160%.
- По умолчанию 100%.
- `Ctrl + 0` — сброс.
- `Ctrl + +` — увеличить.
- `Ctrl + -` — уменьшить.
- Сохранять значение между запусками.
- Пока SQLite нет — localStorage допустим. После SQLite перенести в `app_settings`.

## 3. Применение масштаба
Масштабировать весь интерфейс: редактор, список, сайдбары, toolbar, popover, модалки, настройки, ИИ-чаты.
Не ломать resize панелей, focus mode, tooltip, popover и обычную прокрутку.

## 4. Реализация
- Не использовать грубый `transform: scale()` на всём приложении, если ломаются layout/hitbox.
- Предпочтительно CSS variables и hook/service `useAppZoom`.
- `preventDefault()` только при `event.ctrlKey`.
- Добавить toast `Масштаб: 110%`.
- В `Настройки → Внешний вид` добавить управление `-`, `100%`, `+`.

## 5. Тесты
Добавить тесты: next zoom, min/max, reset, сохранение, игнор wheel без Ctrl, hotkeys.
