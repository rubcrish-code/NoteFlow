# NoteFlow — задача 1. Исправление UX/UI каркаса

Перед началом прочитай `AGENTS.md`, актуальный HTML-макет и `product-spec.md`. Единственный источник дизайна — актуальный HTML. Git commit не выполняй.

## Исправить

1. **Календарь создания заметки**
   - заменить нативный `input type="date"` на собственный date picker в стиле NoteFlow;
   - русские месяцы/дни, переключение месяца и года, выбранная дата, кнопка «Сегодня»;
   - закрытие по клику вне и `Esc`;
   - светлая/тёмная тема;
   - не выходить за границы окна;
   - показывать `ДД.ММ.ГГГГ`, хранить нормализованную дату.

2. **Режим фокуса**
   - кнопка выхода не перекрывает toolbar;
   - поместить её в нормальный поток layout;
   - toolbar остаётся над редактором;
   - выход по кнопке и `Esc`;
   - проверить 1100×700, 1440×900, 1920×1080.

3. **Tooltip панели форматирования**
   - крайние подсказки не обрезаются;
   - использовать portal в `document.body`;
   - удерживать tooltip внутри viewport;
   - поддержать тёмную тему.

4. **Страница «ИИ-чат по базе»**
   - убрать пустую центральную область и сдвиг вправо;
   - история диалогов слева внутри страницы;
   - основной чат занимает всё оставшееся место;
   - поле ввода внизу;
   - корректная работа при раскрытом и компактном сайдбаре.

5. **Выбор цвета тега**
   - кнопка «Цвет» открывает popover;
   - палитра, предпросмотр, HEX-ввод и проверка;
   - применить/отмена;
   - закрытие по клику вне и `Esc`;
   - обе темы;
   - изменение пока хранить в in-memory state.

6. **Архив**
   - добавить «Восстановить» и «Удалить окончательно»;
   - окончательное удаление только после подтверждения;
   - после подтверждения удалить мок-заметку из in-memory state.

7. **Тёмная тема**
   - провести аудит всех экранов;
   - убрать случайные белые поверхности и жёсткие `#fff`;
   - использовать CSS variables;
   - проверить модалки, поля, toolbar, popover, tooltip, toast, чаты, архив, настройки, скроллбары и active/hover.

- Markdown parser;
- SQLite;
- LLM;
- RAG;
- реальное сохранение данных.
