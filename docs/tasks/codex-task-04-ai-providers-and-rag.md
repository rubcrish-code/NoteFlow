# NoteFlow — задача 04. Подключение LLM, ИИ по заметке и RAG

Начинать после SQLite, проектов/тегов и локальных вложений.
Перед началом прочитать `AGENTS.md`, актуальный HTML-макет и `product-spec.md`.
Git commit не выполнять.

## Цель

Сделать реальное подключение локальных и публичных LLM, рабочий ИИ по текущей заметке и ИИ-чат по всей базе.

## Провайдеры

Поддержать:

- OpenAI-compatible API;
- Ollama;
- LM Studio;
- пользовательский endpoint.

Поля:

- название;
- тип;
- Base URL;
- API key;
- chat model;
- embedding model;
- models endpoint;
- chat endpoint;
- embeddings endpoint;
- timeout;
- context size;
- temperature;
- streaming;
- дополнительные HTTP-заголовки.

## Безопасность

- Windows Credential Manager;
- macOS Keychain;
- не хранить ключи в SQLite, localStorage, логах и Git;
- экспорт не включает ключи;
- предупреждать при отправке данных публичному провайдеру.

## Проверка подключения

- получить список моделей;
- тестовый запрос;
- обработать timeout, 401, 404, неверный URL и несовместимое API;
- понятные статусы и ошибки.

## ИИ по текущей заметке

- правый чат;
- streaming;
- контекст заметки или выделения;
- исправить, сократить, расширить, резюме, задачи, продолжить;
- вставить, заменить, вставить ниже или скопировать;
- без автоматического изменения текста.

## Кнопка AI в toolbar

- компактное меню;
- работает с выделением или всей заметкой;
- disabled без провайдера;
- переход в настройки моделей.

## RAG по базе

- chunking;
- embeddings;
- локальный индекс;
- гибридный поиск FTS5 + vector;
- фильтры по проекту, тегу и периоду;
- ответы со ссылками на заметки и фрагменты;
- переход к источнику;
- не отправлять всю базу целиком.

## ИИ-чат по базе

- регулируемые панели;
- история диалогов сохраняется;
- поле ввода закреплено снизу;
- основной чат занимает оставшееся место;
- экран не обрезается.
