# NoteFlow 1.0.0-rc.6

Windows x64 Release Candidate, не финальная v1.0. Пользовательский smoke изменений после RC5 принят.

## Что нового

- Различимая палитра тегов с восстановленным компактным скруглённым оформлением chips.
- Единый лимит новых названий заметок, проектов и тегов: 25 графем, включая составные emoji; счётчики и валидация. Существующие длинные названия не обрезаются автоматически.
- Внутренние ссылки на заметки и выделенные фрагменты с временной подсветкой при переходе; переходы к фрагментам источников RAG.
- Окно выбора заметки сразу показывает список с поиском по названиям и постраничной загрузкой metadata; единое оформление поля ввода.
- Обе команды ссылок доступны в верхнем toolbar и его компактном меню. Кнопка «Шрифт и размер» стала компактнее.
- Обучение с иконками этапов; имя локального профиля указывается перед первым обучением. Убрано дублирование даты заметки, уточнено оформление подсказок.

## Исправления

- Экспорт отдельной заметки в стандартный CommonMark/GFM: частичное и смешанное жирное/курсивное форматирование, списки, цитаты, блоки кода, таблицы и их выравнивание.
- Обычные Markdown marks не заменяются служебным HTML. Расширенное оформление остаётся в lossless Markdown-first storage/sidecar; один переносимый .md не передаёт все возможности rich editor. Старые экспорты по-прежнему импортируются.
- Служебные транзакции поиска и временной подсветки не должны изменять документ или создавать лишнее autosave/CAS increment.
- Уточнена обработка внутренних ссылок и сохранение выделения для ссылки на фрагмент.
- Browser QA сайдбаров и настроек синхронизирован с реальными CSS transitions без изменения согласованной анимации 240 мс, easing или fluid-ширины кнопки «Новая заметка».

## Установка

Windows x64. Рекомендуется **NoteFlow_1.0.0-rc.6_x64-setup.exe** (NSIS, для текущего пользователя). Альтернативы: **NoteFlow_1.0.0-rc.6_x64_ru-RU.msi** и **NoteFlow_1.0.0-rc.6_x64_en-US.msi**. Выберите один тип установщика. `SHA256SUMS.txt` содержит SHA-256 трёх установщиков.

Версия приложения: **1.0.0-rc.6**. MSI ProductVersion: **0.99.6** (`0.99.5 < 0.99.6 < 1.0.0`). Product identifier `com.noteflow.desktop` и UpgradeCode не менялись. Перед обновлением создайте резервную копию важных данных.

## Известные ограничения

- Установщики не подписаны Authenticode; возможны предупреждения SmartScreen. Проверяйте источник и SHA-256, не отключайте защиту Windows.
- Полная матрица clean install / RC5-to-RC6 upgrade / uninstall / reinstall и сохранение реального профиля новыми пакетами: **PENDING TEST ON SECOND PC**. Проверки metadata пакетов не заменяют installer lifecycle QA.
- Windows 10 отдельно не validated; macOS native QA, подпись и notarization ещё pending. Это Windows prerelease, не подтверждение кроссплатформенного Stable.
- Автоматического updater нет; обновление вручную. Неотправленные AI-черновики остаются в рамках текущего запуска, streaming зависит от провайдера.
- Новая публикация не подтверждает отдельный live smoke Bridge/Ollama. Доступность моделей зависит от сервера и credentials.
- Telegram-specific formatting и вставка rich text в Telegram отдельно не validated. Обычная вставка Markdown не гарантирует форматирование Telegram.
- .md не содержит полный sidecar; для сохранения всех данных используйте резервную копию NoteFlow. Внутренние URI требуют NoteFlow, хотя остаются читаемыми Markdown-ссылками.
