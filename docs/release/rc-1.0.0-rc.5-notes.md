# NoteFlow 1.0.0-rc.5

Windows x64 Release Candidate. Это тестовый выпуск, не финальная v1.0.

## Заметки, поиск и организация

- Поиск внутри открытой заметки с подсветкой и переходом между совпадениями; результаты поиска различают обычные и архивные заметки.
- Уточнены меню заметок и проектов, фильтрация по тегам и подсчёт файлов проекта.
- Удаление проекта вместе с заметками требует ввода точного названия и выполняется транзакционно, с очисткой поисковых индексов и безопасным учётом ссылок на ресурсы.
- Новые названия заметок и проектов ограничены 25 символами; старые длинные названия сохраняются.

## Редактор

- Импорт Markdown из меню заметки вставляет содержимое в документ, не заменяя выделенный текст; при изменившемся документе добавляет текст в конец.
- Доработаны инструменты таблиц, переключение заголовков выбранной строки и колонки, выравнивание по ширине и отступы текста.
- Исправлены размеры изображений при масштабировании, позиционирование поиска, меню вставки и drag & drop в редакторе.
- Сохранена Markdown-first совместимость и восстановление расширенного оформления через sidecar, включая частичное подчёркивание жирного текста.

## Интерфейс и настройки

- Согласованы плавные переходы сайдбаров: основной, список заметок, чат заметки, история и источники чата по базе. Ручное изменение ширины не анимируется; reduced motion учитывается.
- Кнопка «Новая заметка» снова занимает доступную ширину сайдбара, с устойчивым расположением иконки и текста.
- Исправлено переполнение настроек при масштабе 160% и максимальной ширине сайдбара.
- Добавлены пояснения к параметрам моделей и резервным копиям; масштаб применяется отдельной кнопкой. Обучение можно открыть повторно из настроек.

## Установка

Рекомендуется **NoteFlow_1.0.0-rc.5_x64-setup.exe** (NSIS). MSI доступны в вариантах ru-RU и en-US. `SHA256SUMS.txt` содержит SHA-256 трёх установщиков. Standalone EXE не является пользовательским релизным артефактом.

Приложение показывает **1.0.0-rc.5**; технический MSI ProductVersion — **0.99.5**, между RC4 (0.99.4) и финальной 1.0.0. Product identifier и UpgradeCode не изменены. Перед обновлением важных данных создайте резервную копию.

## Известные ограничения

- RC не подписан Authenticode; возможны предупреждения SmartScreen. Не отключайте защиту Windows, проверяйте источник и SHA-256.
- Новые пакеты RC5 не прошли отдельную clean-install / upgrade / reinstall / uninstall матрицу. Предыдущая пользовательская проверка installer lifecycle не заменяет её. Windows 10 отдельно не validated.
- Публичный macOS production release, подпись и notarization ещё не validated.
- Updater отсутствует. Неотправленные AI-черновики сохраняются только в пределах текущего запуска; streaming зависит от провайдера.
- Собственный Ctrl+F работает при фокусе в редакторе заметки; это не глобальная горячая клавиша поиска по всей базе.
- Доступность внешних моделей зависит от сервера и credentials; эта публикация не подтверждает новый live smoke Bridge/Ollama.
